# Модуль парсинга CSV для 1С и Bitrix24

Модуль для интеграции 1С с CRM Bitrix24 через CSV-файл.

1С выгружает данные в `bitrix.csv`, после чего Bitrix-агент периодически читает файл, находит соответствующие сделки и обновляет в них:

- сумму сделки (`OPPORTUNITY`);
- статус из 1С (`UF_CRM_1756198758969`).

Связь строки CSV со сделкой выполняется через пользовательское поле сделки `UF_CRM_1730208607985`.

## Возможности

- разбор CSV с разделителем `;`;
- поддержка UTF-8 и удаление BOM в начале файла;
- преобразование данных в массив или JSON;
- сохранение результата в JSON-файл;
- автоматическая обработка CSV через Bitrix-агент;
- пакетный поиск сделок по 500 идентификаторов;
- запись результатов и ошибок в лог-файлы.

## Требования

- установленный 1С-Битрикс;
- установленный модуль CRM;
- PHP с поддержкой стандартных функций `str_getcsv`, `json_encode` и работы с файлами;
- права на чтение файла `bitrix.csv`;
- права на запись в каталог `lib/logs`.

Модуль не использует Composer и сторонние PHP-библиотеки.

## Установка

1. Скопируйте каталог проекта в:

   ```text
   /bitrix/modules/leadspace.parsercsv/
   ```

2. В административной части Bitrix откройте:

   ```text
   Настройки -> Marketplace -> Установленные решения
   ```

3. Найдите модуль **«Парсер для интеграции»** и нажмите **Установить**.

4. Убедитесь, что модуль CRM включен.

Во время установки модуль:

- регистрируется под идентификатором `leadspace.parsercsv`;
- добавляет Bitrix-агент `\AgentFunctions\Agent::run();`;
- копирует административные файлы;
- настраивает запуск агента с интервалом 150 секунд.

При удалении модуля его агент удаляется автоматически. Файлы CSV и логи удаляются только вручную.

## Формат CSV

Файл должен называться `bitrix.csv` и находиться в корне модуля:

```text
/bitrix/modules/leadspace.parsercsv/bitrix.csv
```

Одна строка содержит шесть полей в следующем порядке:

| № | Поле | Описание |
|---:|---|---|
| 1 | `id` | Идентификатор из 1С в формате `префикс-номер`, например `0000-124587` |
| 2 | `date` | Дата из 1С |
| 3 | `amount` | Сумма сделки |
| 4 | `client` | Клиент |
| 5 | `status` | Общий статус |
| 6 | `status_1c` | Статус из 1С, записываемый в CRM |

Разделитель полей: `;`.

Пример:

```csv
0000-124587;11.09.2024;28596.20;Иванова П.В. (Саранск, Крепмастер);Закрыт;Оплачен
0000-124588;11.09.2024;27596.20;Иванова П.В. (Саранск, Крепмастер);Закрыт;В работе
```

Файл может начинаться с UTF-8 BOM. Пустые строки пропускаются. Заголовок по умолчанию не пропускается, поэтому CSV обычно должен быть без строки заголовков.

Важно: агент извлекает номер ID как часть после первого дефиса. Строки без дефиса или без ID не подходят для автоматического сопоставления.

## Как работает агент

Агент `\AgentFunctions\Agent::run()` выполняет следующие действия:

1. Подключает модули `leadspace.parsercsv` и `crm`.
2. Читает `bitrix.csv`.
3. Преобразует строки CSV в массив и сопоставляет ID из файла с `UF_CRM_1730208607985`.
4. Ищет сделки пакетами по 500 ID без проверки прав CRM.
5. Обновляет только сделки, у которых отличается сумма или статус 1С.
6. Записывает результат обработки в лог `deals`.

Агент учитывает часовой пояс `Europe/Moscow` и содержит ограничение по времени запуска. Если агент запущен вне разрешенного периода, обработка не выполняется, а причина записывается в лог ошибок.

## Логи

Логи создаются автоматически в каталоге:

```text
/bitrix/modules/leadspace.parsercsv/lib/logs/
```

Основные файлы:

- `deals.txt` — результат обработки и количество обновленных сделок;
- `error.txt` — ошибки чтения файла, поиска сделок и обновления CRM.

Каталог `lib/logs` создается при первой записи. У пользователя веб-сервера должны быть права на его создание и запись.

## Использование парсера в коде

После подключения модуля доступны классы:

```php
use Bitrix\Main\Loader;
use ParserCSV\ParserCSV;

Loader::includeModule('leadspace.parsercsv');

$parser = new ParserCSV(false);

// Массив записей
$rows = $parser->parseToArray('/path/to/bitrix.csv');

// JSON-строка
$json = $parser->parseToJson('/path/to/bitrix.csv');

// Сохранение результата в JSON
$parser->parseToJsonFile(
    '/path/to/bitrix.csv',
    '/path/to/bitrix.json'
);
```

Конструктор и методы принимают параметр `$skipFirstLine`. Если передать `true`, первая строка файла будет пропущена как заголовок:

```php
$parser = new ParserCSV(true);
$rows = $parser->parseToArray('/path/to/bitrix.csv');
```

## Ручной запуск и проверка

Для ручного запуска агента в Bitrix можно выполнить:

```php
require $_SERVER['DOCUMENT_ROOT'] . '/bitrix/modules/main/include/prolog_before.php';

\Bitrix\Main\Loader::includeModule('leadspace.parsercsv');
echo \AgentFunctions\Agent::run(8);
```

В каталоге `tests/` находятся вспомогательные скрипты:

- `tests/getagents.php` — просмотр и ручной запуск зарегистрированных агентов;
- `tests/test.php` — поиск сделок по ID из CSV;
- `tests/test2.php` — ручной запуск агента.

Тестовые скрипты рассчитаны на запуск внутри Bitrix и требуют авторизации администратора там, где это указано в коде. Не размещайте их в публичной части сайта без дополнительной защиты.

## Настройка полей CRM

Перед использованием проверьте наличие и назначение пользовательских полей сделки:

| Поле | Назначение |
|---|---|
| `UF_CRM_1730208607985` | внешний ID сделки из 1С |
| `UF_CRM_1756198758969` | статус сделки из 1С |

Если ID пользовательских полей отличаются, их необходимо заменить в `lib/classes/agent.php`.

## Ограничения и важные замечания

- Обработка выполняется только для файла с фиксированным именем `bitrix.csv`.
- Источник CSV не удаляется после обработки.
- Сумма преобразуется в число PHP через `(float)`, поэтому формат суммы должен быть совместим с ним.
- CSV обрабатывается построчно; сложные значения с переводами строк внутри кавычек не поддерживаются.
- При нескольких строках с одинаковым ID используется последняя строка из файла.
- Автоматических PHPUnit-тестов в проекте нет.
